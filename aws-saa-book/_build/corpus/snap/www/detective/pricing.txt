## Pricing overview
Amazon Detective is priced based on the volume of data ingested from AWS CloudTrail logs, Amazon Virtual Private Cloud (Amazon VPC) Flow Logs, Amazon Elastic Kubernetes Service (Amazon EKS) audit logs, findings sent from integrated AWS services to AWS Security Hub, and Amazon GuardDuty findings. You are charged per gigabyte (GB) ingested per account/Region/month. There is no additional charge to enable these log sources for analysis or for data stored in Amazon Detective. Amazon Detective maintains up to a year of aggregated data for its analysis. Amazon Detective is available globally. For a complete list of Regions where Amazon Detective is offered, see the AWS Region table.
## Free Trial
You can try Amazon Detective at no additional charge with a 30-day free trial. With the free trial, you get the full Amazon Detective feature set over the 30-day period. During the free trial, you can see projected costs for each account. If you're using AWS Organizations, you can also see the projected cost of all accounts.

## Pricing examples (monthly)
Example #1
Amazon Detective processes
- 500 GB of data ingested from AWS CloudTrail logs, Amazon VPC Flow Logs, Amazon EKS audit logs, and Amazon GuardDuty findings in the US East (N. Virginia) Region.
Charges: 500 x $2.00 (first 1,000 GB/account/Region/month)
= $1,000 per month
Example #2
Amazon Detective processes
- 8,000 GB of data ingested from AWS CloudTrail, Amazon VPC Flow Logs, and Amazon GuardDuty findings in the US East (N. Virginia) Region.
Charges: 1,000 x $2.00 (first 1,000 GB/account/Region/month)
+ 4,000 x $1.00 (next 4,000 GB/account/Region/month)
+ 3,000 x $0.50 (next 5,000 GB/account/Region/month)
= $7,500 per month
Example #3
Amazon Detective processes
- 12,000 GB of data ingested from AWS CloudTrail, Amazon VPC Flow Logs, and Amazon GuardDuty findings in the US East (N. Virginia) Region.
Charges: 1,000 x $2.00 (first 1,000 GB/account/Region/month)
+ 4,000 x $1.00 (next 4,000 GB/account/Region/month)
+ 5,000 x $0.50 (next 5,000 GB/account/Region/month)
+ 2,000 x $0.25 (over 10,000 GB/account/Region/month)
= $9,000 per month
