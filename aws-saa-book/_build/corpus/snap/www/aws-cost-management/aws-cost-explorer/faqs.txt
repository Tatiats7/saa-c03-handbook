### General

#### What are the benefits of using AWS Cost Explorer?
AWS Cost Explorer lets you explore your AWS costs and usage at both a high level and at a detailed level of analysis, and empowering you to dive deeper using a number of filtering dimensions (e.g., AWS Service, Region, Member Account, etc.) AWS Cost Explorer also gives you access to a set of default reports to help you get started, while also allowing you to create custom reports from scratch.
For more information about the breadth of AWS Cost Explorer features, please click here or refer to the Managing your Usage and Costs user guide.
#### What kinds of default reports are available?
Cost Explorer supports five default reports through Reports page – monthly cost by service, monthly cost by linked account, Monthly EC2 running hours costs and usage, Daily costs, and AWS Marketplace costs. A Customer can click on any of these reports to open them in Cost Explorer console.
#### Can I create and save custom AWS Cost Explorer reports?
Yes, you can save your Cost Explorer report along with your filters and group by dimension selections for later use. Your saved reports will appear in Reports page.
#### Does AWS Cost Explorer support AWS cost and usage forecasts?
Yes, Cost Explorer forecasts your AWS cost and usage by analyzing your historical pattern. Cost Explorer estimates your cost and usage for the next 18 months at monthly granularity and for the next 3 months at daily granularity.
#### What can I do with the AWS Cost Explorer API?
The AWS Cost Explorer API is the low-latency, ad-hoc query service that powers AWS Cost Explorer, and is accessible via a command-line interface and supported AWS SDKs. Using the AWS Cost Explorer API, you can build custom, interactive cost management applications without having to set up and maintain any additional infrastructure.
The AWS Cost Explorer API incurs a charge of 0.01 per request. Please note that if your result set is paginated each page counts as a separate request.
To learn more about the AWS Cost Explorer API, please reference the technical documentation.
#### How can I use Amazon Q Developer to analyze my Cost Explorer data?
You can now ask questions about your AWS cost and usage directly in Cost Explorer using suggested prompts or in your own words, powered by Amazon Q Developer. Suggested prompts surface commonly asked cost questions like "Show me my top spending services this month." Click any prompt to instantly receive detailed insights from Amazon Q while Cost Explorer updates to reflect the analysis. The Ask Question button lets you type any cost related question like "What were my highest-cost services last quarter?" with Amazon Q delivering insights alongside corresponding Cost Explorer updates. You can also click 'Analyze with Amazon Q' button on any cost report to receive comprehensive explanations covering your cost trends, top drivers, and anomalies based on your current filters and time period. This works across historical, forecast, and compare views, with follow-up questions to explore findings further. Amazon Q is also accessible via the Q icon across the AWS Management Console for cost questions from any console page.
#### What are suggested prompts in Cost Explorer?
Suggested prompts are commonly asked cost analysis questions displayed in Cost Explorer. Click any prompt to instantly receive detailed insights from Amazon Q Developer alongside an automatically updated Cost Explorer view. The prompts refresh each time you load the page or complete a query, ensuring you always have fresh analytical options to explore.
#### What permissions do I need to use natural language cost analysis in Cost Explorer?
You need your existing Cost Explorer permissions along with Amazon Q Developer permissions (q:StartConversation, q:SendMessage) and the q:PassRequest permission. The quickest way for administrators to grant access is using the AmazonQFullAccess managed policy. For detailed permission configurations, see Security for cost management capabilities in Amazon Q Developer.
#### What does 'Analyze with Amazon Q' do?
'Analyze with Amazon Q' provides intelligent cost explanations for any cost report you've configured in Cost Explorer. Click the button, and Amazon Q analyzes your current filters, date range, and cost data to deliver detailed explanations covering cost trends, top drivers, and anomalies. For historical dates, it explains what drove past changes. For future dates, it delivers forecast explanations with service-level breakdowns. For compare mode, it analyzes differences between two months. You can ask follow-up questions to explore any finding further, including discovering optimization opportunities.
