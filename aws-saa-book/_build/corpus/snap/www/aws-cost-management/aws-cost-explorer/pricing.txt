# AWS Cost Explorer Pricing
Get started for free
Request a pricing quote
## AWS Cost Explorer API
The AWS Cost Explorer API lets you directly access the interactive, ad-hoc query engine that powers AWS Cost Explorer. Each request using your primary billing view, which contains cost management data associated with your account, will incur a cost of $0.01. For requests using custom billing views, each request will incur $0.01 per source. For example, if you combine 5 separate billing views into a single view, that view has 5 sources, making each API request cost $0.05.
## AWS Cost Explorer Hourly Granularity
Cost Explorer supports hourly granularity looking back over 14 days for two features: 1) cost and usage data for all services without resource level details and 2) EC2 resource level data. Cost Explorer offers hourly granularity at a daily charge of $0.00000033 per usage record (which translates to $0.01 per 1,000 usage records monthly). Usage record corresponds to a line item with a specific resource and usage type. For example, one EC2 instance running for 24 hours will generate 24 distinct usage records a day at the hourly granularity.
Cost Explorer bills you daily based on the total hourly usage records hosted in Cost Explorer for the past 14 days. For instance, if you run one EC2 instance all day every day for the past month, and you have hourly granularity enabled, Cost Explorer will host 336 records (24 hours X 14 days) per day and charge you $0.0001 ($0.00000033 per record X 336 records) daily, resulting in $0.003 ($0.0001 daily charge X 30 days) monthly bill.
Once hourly granularity is enabled, you can view data at hourly granularity in three reports: Cost Explorer, Savings Plans Utilization, and Savings Plans Coverage reports. Your cost does not depend on how many reports you use hourly granularity in. You will pay the same price if you use hourly granularity in just one or all three reports.
