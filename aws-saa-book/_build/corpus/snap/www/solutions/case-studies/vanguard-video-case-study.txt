# Vanguard Improves Resilience and Communication Using AWS Well-Architected
Learn how Vanguard uses Amazon Web Services (AWS) solutions and the AWS Well-Architected Tool to better communicate best practices internally and build more resilient applications.
## Overview
Building highly available, resilient applications is an expectation from customers. Hear from Joseph Wagner, Jr., domain architect and cloud specialist at Vanguard about how using the AWS Well-Architected Tool in conjunction with AWS Lambda, AWS Step Functions, and Amazon EventBridge helped the company improve internal communication of best practices among its teams and, ultimately, build more resilient applications for its customers.

Having highly available, resilient apps is an expectation from customers these days. We started with a baseline of the AWS Well-Architected Framework, which has a lot of good value already, [and continuously helps our team] put out the best products available.
Joseph Wagner, Jr.
Domain Architect, Cloud Specialist, Vanguard
