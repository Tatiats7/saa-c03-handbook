# Smartsheet Enhances Deployment Efficiency and Reduces Costs Using Amazon ECS and AWS Fargate
Learn how Smartsheet leverages fully-managed serverless container orchestration to boost deployment frequency and engineering throughput using Amazon ECS and AWS Fargate.
## Overview
Smartsheet relies on Amazon Elastic Container Service (Amazon ECS) with AWS Fargate, a fully-managed, serverless container orchestration service, to improve deployment velocity and engineer capacity. Using a serverless platform on AWS, Smartsheet can deploy more frequently, increase throughput, and reduce the engineering time to deploy from hours to minutes. "We've gone from weekly deployments to deployments that we do multiple times a day, and from what used to be hours of at least two engineers' time, we've been able to shave that down to several minutes," said Skylar Graika, senior principal software engineer at Smartsheet.
Play
## Smartsheet's Solution
Smartsheet used Amazon ECS with AWS Fargate, and AWS CodePipeline to transition from coupled deployments to independent deployments enabling faster, more isolated releases, reducing interdependencies. The company was able to streamline the deployment process, eliminate manual upgrades and patches, and ensure consistent and reliable workloads. Within the last year, Smartsheet was able to scale out its capacity by 50x, and by leveraging deep integrations across AWS services, the company was able to improve efficiencies and simplify its security and compliance process. Additionally, by adopting AWS Graviton with the Fargate deployments, Smartsheet has seen a 20 percent reduction in cost.

## AWS Services Used
### Amazon ECS
Amazon Elastic Container Service (ECS) is a fully managed container orchestration service that helps you to more efficiently deploy, manage, and scale containerized applications.

### AWS Fargate
AWS Fargate is a serverless, pay-as-you-go compute engine that lets you focus on building applications without managing servers.

### AWS Graviton
AWS Graviton is a family of processors designed to deliver the best price performance for your cloud workloads running in Amazon Elastic Compute Cloud (Amazon EC2).
