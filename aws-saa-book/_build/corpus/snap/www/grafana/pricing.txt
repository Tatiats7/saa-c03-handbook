## Why Amazon Managed Grafana?
With Amazon Managed Grafana, there are no upfront fees, no required minimum commitments, and no long-term contracts. You pay only for what you use, based on an active user license per workspace. You will be charged at the end of the month for your usage. An “Active user” is any user that has logged in to an Amazon Managed Grafana workspace or made an API request at least once during a monthly billing cycle.
Amazon Managed Grafana offers a 90-day free trial, with up to five free users per account. Amazon Managed Grafana has three user license types, Amazon Managed Grafana Editor, Amazon Managed Grafana Viewer and Amazon Manager Grafana Enterprise Plugins. Customers with usage beyond the five free users will be billed at the standard Amazon Managed Grafana Editor or Amazon Managed Grafana Viewer and Amazon Managed Grafana Enterprise Plugins user license rates described below.
## Pricing
All user licenses are per workspace, per month. Each workspace requires a minimum of one Amazon Managed Grafana Editor license in order to manage and log into the workspace, even if no users log in. An Amazon Managed Grafana Editor license costs $9 per active editor or administrator user per workspace and provides the user with administrative permissions for managing workspace users, creating and managing dashboards and alerts, and assigning permissions to access data sources. For customers who need only view access, an Amazon Managed Grafana Viewer license costs $5 per active user per workspace and provides the user with view-only access to the Amazon Managed Grafana workspace. Users with view-only access can view dashboards, alerts, and query data sources, but perform no other actions on the workspace.
Grafana API keys are associated with an API user license and can be granted Administrator, Editor, or Viewer permissions. An Amazon Managed Grafana API user license with Administrator or Editor permissions is billed at $9 per active API user or $5 per active API user for an API user license with Viewer permissions. If multiple API keys with different permissions are associated with one API user license, then the higher price will apply. Service accounts are similar to Grafana users and can be enabled/disabled, granted specific permissions, and remain active until they are deleted or disabled. Each Service account is billed as an Amazon Manager Grafana user. An Amazon Managed Grafana service account with Administrator or Editor permissions is billed at $9 per active Service account or $5 per active Service account for a Service account with Viewer permissions.
## Enterprise plugins and support
To access Enterprise Plugins to connect to third-party Enterprise data sources listed here, an Amazon Managed Grafana Enterprise Plugins license costs an additional $45 per active user per workspace. With this upgrade, you can also access support and on-demand training directly from Grafana Labs.

## Pricing examples
Note: Pricing values displayed here are meant to be examples only.
### Example 1 - Managing multiple user access to an Amazon Managed Grafana Workspace
In this example, you have granted 100 Editors and 100 Viewers access to your Grafana workspace. In the month of January, only 20 Editors and 30 Viewers log in to the workspace. Since billing is based on active users, the total number of users that will be billed is 20 Editors and 30 Viewers for the month of January.
Total Amazon Managed Grafana Monthly charges = 20 * $9.00 (Editor license) + 30 * $5.00 (Viewer license) = $330.00
### Example 2 - Upgrading an Amazon Managed Grafana Workspace to access Enterprise plugins
In this example, you have granted 100 Editors and 100 Viewers access to your Grafana workspace. You have also upgraded the workspace to Enterprise plugins. In the month of January, only 20 Editors and 30 Viewers log in to the workspace. Since billing is based on active users, the total number of users that will be billed is 20 Editors and 30 Viewers for the month of January.
Total Amazon Managed Grafana Monthly charges = 20 * $9.00 (Editor license) + 30 * $5.00 (Viewer license) = $330.00
Total Enterprise Plugins Monthly charges = 20 * $45 (Active enterprise user license) + 30 * $45 (Active enterprise user license) = $2,250.00
Total Monthly Bill = $330 for Amazon Managed Grafana + $2250 for Enterprise plugins = $2,580.00
### Example 3 – Minimum one Editor user per Amazon Managed Grafana workspace
In this example, you have created two workspaces. Workspace A and Workspace B both have 10 users that have been granted permission to access the workspace. In the month of January, no users log into workspace A, which will incur a minimum one Editor user license for workspace A, but the other inactive users that have been granted permission but have not actively logged in that month are not billed. Workspace B had 1 Administrator, 1 Editor, and 3 Viewers log in for the month of January.
Workspace A monthly charges = 1 * $9.00 (Editor license) = $9.00
Workspace B monthly charges = 2 * $9.00 (Editor license) + 3 * $5.00 (Viewer license) = $33.00
Total Monthly Bill = $9.00 for Workspace A + $33.00 for Workspace B = $42.00
### Example 4 – Amazon Managed Grafana Workspace with active users and API users
In this example, you have created one Amazon Managed Grafana workspace with 2 API keys, one with Administrator and one with Viewer permissions that are both associated to one Grafana API user. You have also granted 10 Editor users and 50 Viewer users access to your Grafana workspace. In the month of January, both the Administrator and Viewer API keys were used to create, edit, and view dashboards, with 5 Editor users and 10 Viewer users that have also logged into the workspace. Since both API keys are associated with one Grafana API user, you will only be billed for one API user license, with the higher Administrator price being applied. Additionally, since billing is based on active users, the total number of users that will be billed is 5 Editors and 10 Viewers for the month of January.
Total API monthly charges = 1 * $9.00 (Editor license) = $9.00
Total active user charges = 5 * $9.00 (Editor license) + 10 (viewers) * $5.00 (Viewer license) = $95.00
Total Monthly Bill = $9.00 for API user license + $95.00 for active user licenses = $104.00
### Example 5 – Amazon Managed Grafana Workspace with active users and Service accounts
In this example, you have created one Amazon Managed Grafana workspace with 2 Service accounts, one with Administrator and one with Viewer permissions. You have also granted 10 Editor users and 50 Viewer users access to your Grafana workspace. In the month of January, both the Administrator and Viewer Service accounts were used to create, edit, and
view dashboards, with 5 Editor users and 10 Viewer users that have also logged into the workspace. You will be billed for 1 Editor Service account and 1 Viewer Service account. Additionally, since billing is based on active users, the total number of users that will be billed is 5 Editors and 10 Viewers for the month of January.
Total Service account monthly charges = 1 * $9.00 (Editor Service account) + 1 * $5.00 (Viewer Service account) = $14.00
Total active user charges = 5 * $9.00 (Editor license) + 10 (viewers) * $5.00 (Viewer license) = $95.00
Total Monthly Bill = $14.00 for Service account licenses + $95.00 for active user licenses = $109.00
