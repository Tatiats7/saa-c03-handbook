## Data Transfer pricing
This pricing is based on data transferred "in" to and "out" of the AWS Storage Gateway Service by your gateway, and it varies by region and gateway host. For file storage, where data is stored directly in your Amazon Simple Storage Service (S3) buckets, please refer to Amazon S3 Data Transfer Pricing. For data transfer over AWS Direct Connect, see Data Transfer User Guide and Pricing. Contact sales for custom pricing in unusual situations.
Data Transfer OUT from the AWS Storage Gateway service to an Amazon EC2-based gateway appliance in the same region is $0.00 per GB.
