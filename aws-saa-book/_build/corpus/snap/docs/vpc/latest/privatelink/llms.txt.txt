# Amazon Virtual Private Cloud AWS PrivateLink

> Use AWS PrivateLink to connect your VPC to supported AWS services, services hosted by other AWS accounts, and supported AWS Marketplace partner services.

- [Get started](https://docs.aws.amazon.com/vpc/latest/privatelink/getting-started.md)
- [Access SaaS products](https://docs.aws.amazon.com/vpc/latest/privatelink/privatelink-access-saas.md)
- [CloudWatch metrics](https://docs.aws.amazon.com/vpc/latest/privatelink/privatelink-cloudwatch-metrics.md)
- [Quotas](https://docs.aws.amazon.com/vpc/latest/privatelink/vpc-limits-endpoints.md)
- [Document history](https://docs.aws.amazon.com/vpc/latest/privatelink/doc-history.md)

## [What is AWS PrivateLink?](https://docs.aws.amazon.com/vpc/latest/privatelink/what-is-privatelink.md)

- [Concepts](https://docs.aws.amazon.com/vpc/latest/privatelink/concepts.md): Use AWS PrivateLink to establish connectivity between the resources in your VPC private subnets and VPC endpoint services that are outside your VPC.

- [Receive alerts for interface endpoint events](https://docs.aws.amazon.com/vpc/latest/privatelink/manage-notifications-endpoint.md): Receive alerts for specific events related to your interface VPC endpoint.
- [Delete an interface endpoint](https://docs.aws.amazon.com/vpc/latest/privatelink/delete-interface-endpoint.md): Learn how to delete an interface VPC endpoint.

### [Gateway endpoints](https://docs.aws.amazon.com/vpc/latest/privatelink/gateway-endpoints.md)

Learn how to use gateway endpoints to connect to Amazon S3 and Amazon DynamoDB.

- [Endpoints for Amazon S3](https://docs.aws.amazon.com/vpc/latest/privatelink/vpc-endpoints-s3.md): Use gateway endpoints to connect privately to Amazon S3.
- [Endpoints for DynamoDB](https://docs.aws.amazon.com/vpc/latest/privatelink/vpc-endpoints-ddb.md): Use gateway endpoints to connect privately to Amazon DynamoDB.
