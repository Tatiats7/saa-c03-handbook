### [Using the metric query editor](https://docs.aws.amazon.com/grafana/latest/userguide/CloudWatch-using-the-metric-query-editor.md)

The metric query editor allows you to build three types of queries - Metric Search, Metric Query, and PromQL.

- [Using the metric search option](https://docs.aws.amazon.com/grafana/latest/userguide/CloudWatch-using-the-metric-search.md): To create a valid query in Metric Search, you must specify the namespace, metric name and at least one statistic.
- [Using the metric query option to query CloudWatch Metrics Insights data](https://docs.aws.amazon.com/grafana/latest/userguide/CloudWatch-using-the-metric-query.md)
- [Using the PromQL query option](https://docs.aws.amazon.com/grafana/latest/userguide/CloudWatch-using-promql.md)
- [Using the Amazon CloudWatch Logs query editor](https://docs.aws.amazon.com/grafana/latest/userguide/CloudWatch-using-the-logs-query-editor.md): To query CloudWatch Logs, select the Region and up to 20 log groups that you want to query.
- [Curated dashboards](https://docs.aws.amazon.com/grafana/latest/userguide/CloudWatch-curated-dashboards.md): The updated CloudWatch data source ships with pre-configured dashboards for five of the most popular AWS services:
- [Templated queries](https://docs.aws.amazon.com/grafana/latest/userguide/cloudwatch-templated-queries.md): Instead of hardcoding details such as servers, applications, and sensor names in your metric queries, you can use variables in their place.
- [Using ec2_instance_attribute examples](https://docs.aws.amazon.com/grafana/latest/userguide/cloudwatch-ec2-instance-attribute-examples.md)
- [Using JSON format template variables](https://docs.aws.amazon.com/grafana/latest/userguide/cloudwatch-using-json-format-template-variables.md): Some queries accept filters in JSON format and Grafana supports the conversion of template variables to JSON.
- [Pricing](https://docs.aws.amazon.com/grafana/latest/userguide/cloudwatch-pricing.md): The Amazon CloudWatch data source for Grafana uses the ListMetrics and GetMetricData CloudWatch API calls to list and retrieve metrics.
- [Service quotas](https://docs.aws.amazon.com/grafana/latest/userguide/cloudwatch-service-quotas.md): AWS defines quotas, or limits, for resources, operations, and items in your AWS account.
- [Cross-account observability](https://docs.aws.amazon.com/grafana/latest/userguide/cloudwatch-cross-account.md)
