### [Gaining insights with ML](https://docs.aws.amazon.com/quick/latest/userguide/making-data-driven-decisions-with-ml-in-quicksight.md)

How to use Amazon Quick Sight and AWS machine learning to help you make data-driven decisions.

### [Understanding the ML algorithm](https://docs.aws.amazon.com/quick/latest/userguide/concept-of-ml-algorithms.md)

- [What's the difference between anomaly detection and forecasting?](https://docs.aws.amazon.com/quick/latest/userguide/difference-between-anomaly-detection-and-forecasting.md): Anomaly detection identifies outliers and their contributing drivers to answer the question "What happened that doesn't usually happen?" Forecasting answers the question "If everything continues to happen as expected, what happens in the future?" The math that allows forecasting also enables us to ask "If a few things change, what happens then?"
- [What is RCF?](https://docs.aws.amazon.com/quick/latest/userguide/what-is-random-cut-forest.md): A random cut forest (RCF) is a special type of random forest (RF) algorithm, a widely used and successful technique in machine learning.
- [How RCF is applied to detect anomalies](https://docs.aws.amazon.com/quick/latest/userguide/how-does-rcf-detect-anomalies.md): A human can easily distinguish a data point that stands out from the rest of the data.
- [How RCF is applied to generate forecasts](https://docs.aws.amazon.com/quick/latest/userguide/how-does-rcf-generate-forecasts.md): To forecast the next value in a stationary time sequence, the RCF algorithm answers the question "What would be the most likely completion, after we have a candidate value?" It uses a single tree in RCF to perform a search for the best candidate.
- [References for machine learning and RCF](https://docs.aws.amazon.com/quick/latest/userguide/learn-more-about-machine-learning-and-rcf.md): To learn more about machine learning and this algorithm, we suggest the following resources:
- [Dataset requirements](https://docs.aws.amazon.com/quick/latest/userguide/ml-data-set-requirements.md): Work with dataset requirements when using ML insights with Amazon Quick Sight.
