## [Runtime Monitoring](https://docs.aws.amazon.com/guardduty/latest/ug/runtime-monitoring.md)

### [How it works](https://docs.aws.amazon.com/guardduty/latest/ug/how-does-runtime-monitoring-work.md)

Runtime Monitoring uses a lightweight security agent to observe the runtime behavior of your Amazon EC2, Amazon EKS, and Amazon ECS on Fargate workloads and detect threats.

- [Enablement](https://docs.aws.amazon.com/guardduty/latest/ug/runtime-monitoring-enablement.md): Enabling Runtime Monitoring is a two-step process:
- [Deploy to Amazon EKS](https://docs.aws.amazon.com/guardduty/latest/ug/how-runtime-monitoring-works-eks.md): GuardDuty Runtime Monitoring monitors your Amazon EKS clusters for threats by deploying the GuardDuty security agent to them.
- [Deploy to Amazon EC2](https://docs.aws.amazon.com/guardduty/latest/ug/how-runtime-monitoring-works-ec2.md): GuardDuty Runtime Monitoring monitors your Amazon EC2 instances for threats by deploying the GuardDuty security agent to them.
- [Deploy to Amazon ECS on Fargate](https://docs.aws.amazon.com/guardduty/latest/ug/how-runtime-monitoring-works-ecs-fargate.md): GuardDuty Runtime Monitoring monitors your Amazon ECS clusters on Fargate for threats by deploying the GuardDuty security agent to them.
- [Agent connectivity](https://docs.aws.amazon.com/guardduty/latest/ug/runtime-monitoring-agent-connectivity.md): Learn how the Runtime Monitoring security agent connects to GuardDuty to deliver runtime events.
- [Tracking Runtime Monitoring coverage](https://docs.aws.amazon.com/guardduty/latest/ug/runtime-monitoring-after-configuration.md): Learn more about what to expect after you have enabled Runtime Monitoring and deployed the GuardDuty security agent.

### [30-day free trial](https://docs.aws.amazon.com/guardduty/latest/ug/runtime-monitoring-free-trial-works.md)
