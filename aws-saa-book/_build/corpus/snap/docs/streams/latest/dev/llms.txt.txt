# Amazon Kinesis Data Streams Developer Guide

> This is official Amazon Web Services (AWS) documentation for Amazon Kinesis Data Streams. With Kinesis Data Streams, you can build custom applications that process or analyze streaming data for specialized needs. It can continuously capture and store terabytes of data per hour from hundreds of thousands of sources such as website clickstreams, financial transactions, social media feeds, IT logs, and location-tracking events. With the Kinesis Client Library (KCL), you can build Kinesis applications and use streaming data to power real-time dashboards, generate alerts, implement dynamic pricing and advertising, and more. You can also emit data from Kinesis Data Streams to other AWS services such as Amazon Simple Storage Service (Amazon S3), Amazon Redshift, Amazon EMR, and AWS Lambda. This guide provides a conceptual overview of Kinesis Data Streams and includes detailed instructions for using the service.

### [KPL and KCL compatibility](https://docs.aws.amazon.com/streams/latest/dev/service-managed-pk-kpl.md)

Learn about Amazon Kinesis Producer Library (KPL) and Kinesis Client Library (KCL) compatibility with service-managed record distribution in Amazon Kinesis Data Streams.

- [Upgrade KPL to send null partition keys](https://docs.aws.amazon.com/streams/latest/dev/service-managed-pk-kpl-upgrade-for-null.md): To send records without providing a partition key to a service-managed stream, you must upgrade to the latest KPL version.
- [Grant DescribeStreamSummary permission to the KPL](https://docs.aws.amazon.com/streams/latest/dev/service-managed-pk-kpl-permissions.md): The updated KPL calls the DescribeStreamSummary API to detect whether a stream uses service-managed record distribution (AUTO).
- [No changes required for existing producers and consumers](https://docs.aws.amazon.com/streams/latest/dev/service-managed-pk-kpl-no-changes.md): If you continue to provide a partition key in your PutRecord and PutRecords API calls, and your producer does not use KPL aggregation, no KPL or KCL changes are required.
- [Aggregation is not supported on service-managed streams](https://docs.aws.amazon.com/streams/latest/dev/service-managed-pk-kpl-aggregation.md): KPL aggregation is not supported on streams configured with service-managed record distribution, in any KPL version.
- [KCL considerations](https://docs.aws.amazon.com/streams/latest/dev/service-managed-pk-kpl-kcl-considerations.md): If you use the Kinesis Client Library (KCL) to consume from service-managed streams, no KCL changes are required.
- [Summary](https://docs.aws.amazon.com/streams/latest/dev/service-managed-pk-kpl-summary.md)
