# AWS Direct Connect User Guide

> Direct Connect links your internal network to a Direct Connect location over fiber-optic cable. One end of the cable is connected to your router and the other to a Direct Connect router. With this connection in place, you can create virtual interfaces directly to the AWS cloud (for example, to Amazon EC2 and Amazon S3), bypassing Internet service providers in your network path.
