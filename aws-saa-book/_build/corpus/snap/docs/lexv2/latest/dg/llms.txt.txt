- [Initial response](https://docs.aws.amazon.com/lexv2/latest/dg/intent-initial.md): The initial response is sent to the user after Amazon Lex V2 determines the intent and before it starts to elicit slot values.

### [Slots](https://docs.aws.amazon.com/lexv2/latest/dg/intent-slots.md)

Slots are values provided by the user to fulfill the intent.

- [Re-eliciting slots](https://docs.aws.amazon.com/lexv2/latest/dg/reelicit-slots.md): You can configure your bot to re-elicit a slot that has already been filled by setting that slot value to null and setting the next step in the conversation to loop back to eliciting that slot.
- [Using multiple values in a slot](https://docs.aws.amazon.com/lexv2/latest/dg/multi-valued-slots.md): Learn how to create intents that accept multiple values in a single slot.
- [Confirmation](https://docs.aws.amazon.com/lexv2/latest/dg/intent-confirm.md): After the conversation with the user is complete and the slot values for the intent are filled, you can configure a confirmation prompt to ask the user if the slot values are correct.
- [Fulfillment](https://docs.aws.amazon.com/lexv2/latest/dg/intent-fulfillment.md): After all the slot values are provided by the user for the intent, Amazon Lex V2 fulfills the user’s request.
- [Closing response](https://docs.aws.amazon.com/lexv2/latest/dg/intent-closing.md): The closing response is sent to your user after their intent is fulfilled.

### [Adding slot types](https://docs.aws.amazon.com/lexv2/latest/dg/add-slot-types.md)

Slot types define the values that users can supply for your intent variables.

### [Built-in slot types](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slots.md)

Amazon Lex supports built-in slot types that define how data in the slot is recognized and handled.

- [AMAZON.AlphaNumeric](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-alphanumeric.md): Recognizes strings made up of letters and numbers, such as APQ123.
- [AMAZON.City](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-city.md): Provides a list of local and world cities.
- [AMAZON.Confirmation](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-confirmation.md): This slot type recognizes input phrases that corresponds to 'Yes', 'No', 'Maybe', and 'Don't know' phrases and words for Amazon Lex V2 and converts it one of the four values.
- [AMAZON.Country](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-country.md): The names of countries around the world.
- [AMAZON.Currency](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-currency.md): Converts words that represent a currency into a standard ISO 4217 alphabetic currency code and a number.
- [AMAZON.Date](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-date.md): Converts words that represent dates into a date format.
- [AMAZON.Duration](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-duration.md): Converts words that indicate durations into a numeric duration.
- [AMAZON.EmailAddress](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-email.md): Recognizes words that represent an email address provided as username@domain.
- [AMAZON.FirstName](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-first-name.md): Commonly used first names.
- [AMAZON.LastName](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-last-name.md): Commonly used last names.
- [AMAZON.Number](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-number.md): Converts words or numbers that express a number into digits, including decimal numbers.
- [AMAZON.Percentage](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-percent.md): Converts words and symbols that represent a percentage into a numeric value with a percent sign (%).
- [AMAZON.PhoneNumber](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-phone.md): Converts the numbers or words that represent a phone number into a string format without punctuation as follows.
- [AMAZON.State](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-state.md): The names of geographical and political regions within countries.
- [AMAZON.StreetName](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-street-name.md): The names of streets within a typical street address.
- [AMAZON.Time](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-time.md): Converts words that represent times into time values.
- [AMAZON.UKPostalCode](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-uk-postal-code.md): Converts words that represent a UK postal code to a standard format for postal codes in the United Kingdom.
- [AMAZON.FreeFormInput](https://docs.aws.amazon.com/lexv2/latest/dg/built-in-slot-free-form.md): AMAZON.FreeFormInput can be used to capture free form input from the end user.
- [Custom slot type](https://docs.aws.amazon.com/lexv2/latest/dg/custom-slot-types.md): Learn how to create your own custom slot types for your Amazon Lex V2 intents.
