## [AWS Deployment Services](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/aws-deployment-services.md)

- [AWS CloudFormation](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/aws-cloudformation.md): AWS CloudFormation is a service that enables customers to provision and manage almost any AWS resource using a custom template language expressed in YAML or JSON.
- [AWS Elastic Beanstalk](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/aws-elastic-beanstalk.md): AWS Elastic Beanstalk is an easy-to-use service for deploying and scaling web applications and services developed with Java, .NET, .NET Core, PHP, Node.js, Python, Ruby, Go, or Docker on familiar servers such as Apache, Nginx, Passenger, and IIS.
- [AWS CodeDeploy](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/aws-codedeploy.md): AWS CodeDeploy is a fully managed deployment service that automates application deployments to compute services such as Amazon EC2, Amazon Elastic Container Service (Amazon ECS), AWS Lambda, or on-premises servers.
- [Amazon Elastic Container Service](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/amazon-elastic-container-service.md): Amazon Elastic Container Service (Amazon ECS) is a fully managed container orchestration service that supports Docker containers and allows you to easily run applications on a managed cluster.
- [Amazon Elastic Kubernetes Service](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/amazon-elastic-kubernetes-service.md): Amazon Elastic Kubernetes Service (Amazon EKS) is a fully-managed, certified Kubernetes conformant service that simplifies the process of building, securing, operating, and maintaining Kubernetes clusters on AWS.
- [AWS App Runner](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/aws-apprunner.md): AWS App Runner is a fully managed container application service that lets you build, deploy, and run containerized web applications and API services without prior infrastructure or container experience.
- [Amazon Lightsail](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/lightsail.md): Amazon Lightsail is a simple and cost-effective cloud service that makes it easy for small businesses, startups, and individuals to deploy and manage their applications in the cloud.
- [Red Hat OpenShift Service on AWS](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/red-hat-openshift.md): Red Hat OpenShift Service on AWS (ROSA) is a managed service that’s available through the AWS Management Console.
- [AWS Local Zones](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/aws-local-zones.md): An AWS Local Zone is an extension of an AWS Region in close geographic proximity to your users.
- [AWS Wavelength](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/wavelength.md): AWS Wavelength is an AWS infrastructure that allows you to deploy workloads closer to 5G-connected users and devices.
- [Additional Deployment Services](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/additional-deployment-services.md)


## [Deployment strategies](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/deployment-strategies.md)

- [Prebaking vs. bootstrapping AMIs](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/prebaking-vs.-bootstrapping-amis.md): If your application relies heavily on customizing or deploying applications onto Amazon EC2 instances, then you can optimize your deployments through bootstrapping and prebaking practices.
- [Blue/green deployments](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/bluegreen-deployments.md): A blue/green deployment is a deployment strategy in which you create two separate, but identical environments.
- [Rolling deployments](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/rolling-deployments.md): A rolling deployment is a deployment strategy that slowly replaces previous versions of an application with new versions of an application by completely replacing the infrastructure on which the application is running.
- [Canary deployments](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/canary-deployments.md): Canary deployments are a type of blue/green deployment strategy that is more risk-averse.
- [In-place deployments](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/in-place-deployments.md): An in-place deployment is a deployment strategy that updates the application version without replacing any infrastructure components.
- [Combining Deployment Services](https://docs.aws.amazon.com/whitepapers/latest/overview-deployment-options/combining-deployment-services.md): There is not a “one size fits all” deployment solution on AWS.
