# Streaming Data Solutions on AWS AWS Whitepaper

> Data engineers, data analysts, and big data developers are looking to evolve their analytics from batch to real-time so their companies can learn about what their customers, applications, and products are doing right now and react promptly. This whitepaper discusses the evolution of analytics from batch to real-time. It describes how services such as Amazon Kinesis Data Streams, Amazon Data Firehose, and Amazon Managed Service for Apache Flink can be used to implement real-time applications, and provides common design patterns using these services.
