## [Encryption best practices for AWS services](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/services-best-practices.md)

- [AWS CloudTrail](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/cloudtrail.md): Review best practices and recommendations for encrypting data in AWS CloudTrail.
- [Amazon DynamoDB](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/dynamodb.md): Review best practices and recommendations for encrypting data in Amazon DynamoDB.
- [Amazon Elastic Compute Cloud and Amazon Elastic Block Store](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/ec2-ebs.md): Review best practices and recommendations for encrypting data in Amazon Elastic Compute Cloud (Amazon EC2) and Amazon Elastic Block Store (Amazon EBS).
- [Amazon Elastic Container Registry](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/ecr.md): Review best practices and recommendations for encrypting data in Amazon Elastic Container Registry (Amazon ECR).
- [Amazon Elastic Container Service](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/ecs.md): Review best practices and recommendations for encrypting data in Amazon Elastic Container Service (Amazon ECS).
- [Amazon Elastic File System](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/efs.md): Review best practices and recommendations for encrypting data in Amazon Elastic File System (Amazon EFS).
- [Amazon Elastic Kubernetes Service](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/eks.md): Review best practices and recommendations for encrypting data in Amazon Elastic Kubernetes Service (Amazon EKS).
- [AWS Encryption SDK](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/encryption-sdk.md): Review best practices and recommendations for using the AWS Encryption SDK to encrypt your data in the AWS Cloud.
- [AWS Key Management Service](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/kms.md): Review best practices and recommendations for using AWS Key Management Service (AWS KMS) to manage encryption keys.
- [AWS Lambda](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/lambda.md): Review best practices and recommendations for encrypting data in AWS Lambda.
- [Amazon Relational Database Service](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/rds.md): Review best practices and recommendations for encrypting data in Amazon Relational Database Service (Amazon RDS).
- [AWS Secrets Manager](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/secrets-manager.md): Review best practices and recommendations for encrypting secrets in AWS Secrets Manager.
- [Amazon Simple Storage Service](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/s3.md): Review best practices and recommendations for encrypting data in Amazon Simple Storage Service (Amazon S3).
- [Amazon Virtual Private Cloud](https://docs.aws.amazon.com/prescriptive-guidance/latest/encryption-best-practices/vpc.md): Review best practices and recommendations for encrypting data in transit when using Amazon Virtual Private Cloud (Amazon VPC).
