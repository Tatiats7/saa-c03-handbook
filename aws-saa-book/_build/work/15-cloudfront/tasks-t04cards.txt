cloudfront-oac-bucket-policy-cloudfront-service-principal
  claim: The S3 bucket policy for OAC allows the CloudFront service principal (cloudfront.amazonaws.com) to access the bucket, and a Condition element limits it to requests on behalf of the distribution that contains the S3 origin.
  scope: CloudFront OAC, S3 bucket policy.
  link: [CloudFront service principal (cloudfront.amazonaws.com)](../facts/cloudfront.md#cloudfront-oac-bucket-policy-cloudfront-service-principal)
  link: [only when the request is on behalf](../facts/cloudfront.md#cloudfront-oac-bucket-policy-cloudfront-service-principal)
cloudfront-oac-signing-always-recommended
  claim: The recommended OAC signing behavior is Sign requests (always), with which CloudFront signs all requests it sends to the S3 bucket origin.
  scope: CloudFront OAC signing behavior; default; not adjustable.
  link: [Sign requests (recommended)](../facts/cloudfront.md#cloudfront-oac-signing-always-recommended)
  link: [CloudFront always signs all requests](../facts/cloudfront.md#cloudfront-oac-signing-always-recommended)
cloudfront-private-s3-oac-plus-signed-urls
  claim: You can secure S3 content so users reach it through the CloudFront distribution but not directly through S3 URLs, which prevents bypassing CloudFront; this step is not required for signed URLs but is recommended.
  scope: CloudFront private content, S3 origin.
  link: [cannot access it directly by using Amazon S3 URLs](../facts/cloudfront.md#cloudfront-private-s3-oac-plus-signed-urls)
  link: [This prevents someone from bypassing CloudFront](../facts/cloudfront.md#cloudfront-private-s3-oac-plus-signed-urls)
cloudfront-oac-object-ownership-bucket-owner-enforced
  claim: With OAC on an S3 bucket origin, Object Ownership must be set to Bucket owner enforced, which is the default for new S3 buckets; Bucket owner preferred is the setting to use if ACLs are required.
  scope: CloudFront OAC, S3 origin.
  link: [Bucket owner enforced](../facts/cloudfront.md#cloudfront-oac-object-ownership-bucket-owner-enforced)
  link: [Bucket owner preferred](../facts/cloudfront.md#cloudfront-oac-object-ownership-bucket-owner-enforced)
cloudfront-oac-never-sign-needs-public-bucket
  claim: With the origin access control setting Do not sign requests (never in the API, CLI and CloudFormation), the S3 bucket origin must be publicly accessible; with a bucket that is not publicly accessible, CloudFront cannot access the origin, and CloudFront passes the S3 errors on to viewers.
  scope: CloudFront OAC signing behavior.
  link: [the S3 bucket origin must be publicly accessible](../facts/cloudfront.md#cloudfront-oac-never-sign-needs-public-bucket)
  link: [CloudFront cannot access the origin](../facts/cloudfront.md#cloudfront-oac-never-sign-needs-public-bucket)
