inspector-ec2-hybrid-default
  claim: The Amazon Inspector guide states that when you activate Amazon Inspector (or Amazon EC2 scanning) for the first time, the account is automatically enrolled in hybrid scanning, which uses agent-based scanning for instances with the SSM agent installed and configured and agentless scanning for eligible EBS-backed instances that aren't SSM managed. One sentence in the scan mode section of the same page instead calls agent-based scanning the default scan mode for newly activated accounts.
  scope: per AWS account; default; adjustable; the EC2 scanning page contradicts itself once; three statements on two pages say hybrid scanning is enabled automatically.
  link: [automatically enrolled in hybrid scanning](../facts/inspector.md#inspector-ec2-hybrid-default)
  link: [which uses both scan methods](../facts/inspector.md#inspector-ec2-hybrid-default)
  link: [For eligible instances that aren't SSM managed](../facts/inspector.md#inspector-ec2-hybrid-default)
