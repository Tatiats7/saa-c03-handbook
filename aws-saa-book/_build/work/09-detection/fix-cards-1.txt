guardduty-runtime-needs-security-agent
  claim: Runtime Monitoring uses a GuardDuty security agent; you can let GuardDuty install and update the agent automatically or manage it manually, except for Fargate on Amazon ECS.
  scope: per monitored resource type.
  link: [uses a GuardDuty security agent](../facts/guardduty.md#guardduty-runtime-needs-security-agent)
  link: [install and update the security agent](../facts/guardduty.md#guardduty-runtime-needs-security-agent)
config-faq-aggregation-reporting-only-use-stacksets
  claim: The Config data aggregation capability cannot provision rules across accounts; it is reporting only. Use CloudFormation StackSets to provision rules across accounts and Regions.
  link: [It is purely a reporting capability](../facts/config.md#config-faq-aggregation-reporting-only-use-stacksets)
  link: [use AWS CloudFormation StackSets](../facts/config.md#config-faq-aggregation-reporting-only-use-stacksets)
config-guide-continuous-or-daily-recording
  claim: AWS Config supports continuous recording, which records configuration changes whenever they occur, and daily recording, which gives a configuration item with the most recent state over the last 24-hour period only if it differs from the previous one.
  scope: per configuration recorder.
  link: [record configuration changes continuously whenever a change occurs](../facts/config.md#config-guide-continuous-or-daily-recording)
  link: [the most recent state of your resources over the last 24-hour period](../facts/config.md#config-guide-continuous-or-daily-recording)
  say: the most recent state over the last twenty-four hours
guardduty-first-enable-all-plans-except-runtime
  claim: When you use GuardDuty for the first time in an AWS Region, your account is enrolled in a 30-day free trial in that Region and some protection plans are enabled automatically and included in it. Runtime Monitoring, the On-demand malware scan of Malware Protection for EC2, Malware Protection for S3 and Malware Protection for AWS Backup are not enabled by default.
  scope: per AWS account per Region, first use of GuardDuty; default; adjustable; the pricing page table lists which plans are enabled by default.
  link: [Some of the protection plans will also get enabled automatically](../facts/guardduty.md#guardduty-first-enable-all-plans-except-runtime)
  link: [30-day free trial](../facts/guardduty.md#guardduty-first-enable-all-plans-except-runtime)
guardduty-eventbridge-new-findings-near-real-time
  claim: GuardDuty sends notifications for newly generated findings to EventBridge in near real-time; by default, you cannot modify this frequency.
  scope: per newly generated finding; default; not adjustable; by default the frequency cannot be modified.
  link: [near real-time](../facts/guardduty.md#guardduty-eventbridge-new-findings-near-real-time)

detective-behavior-graph-definition
  claim: A behavior graph is a linked set of extracted and analyzed data from one or more AWS accounts; the account that enables Detective becomes the administrator account of the graph and invites or enables member accounts to contribute data.
  scope: per behavior graph.
  link: [a linked set of extracted and analyzed data](../facts/detective.md#detective-behavior-graph-definition)
  link: [becomes the administrator account for a behavior graph](../facts/detective.md#detective-behavior-graph-definition)
artifact-faq-account-vs-organization-agreements
  claim: An Artifact account agreement applies only to the account that accepted it; an organization agreement applies to all accounts in the organization, and only the management account can accept it.
  link: [Only the management account in an organization](../facts/artifact.md#artifact-faq-account-vs-organization-agreements)
macie-unsupported-storage-classes
  claim: Macie doesn't analyze S3 objects that use other storage classes, such as S3 Glacier Deep Archive or S3 Express One Zone, and doesn't analyze objects stored in S3 directory buckets; the supported storage classes include S3 Glacier Instant Retrieval, S3 Intelligent-Tiering and S3 One Zone-IA.
  link: [such as S3 Glacier Deep Archive or S3 Express One Zone](../facts/macie.md#macie-unsupported-storage-classes)
  link: [Macie doesn't analyze objects that are stored in S3 directory buckets.](../facts/macie.md#macie-unsupported-storage-classes)

security-hub-cspm-default-standards
  claim: The default security standards of Security Hub CSPM are currently the AWS Foundational Security Best Practices standard and the CIS AWS Foundations Benchmark v1.2.0 standard. With local configuration, Security Hub CSPM can automatically enable them for new member accounts when they join the organization; you can turn this off only if you integrate with AWS Organizations and use local configuration, and with central configuration you instead use a configuration policy.
  scope: per member account (local configuration); default; adjustable; local configuration with AWS Organizations; central configuration uses a policy instead.
  link: [the AWS Foundational Security Best Practices standard](../facts/security-hub.md#security-hub-cspm-default-standards)
  link: [CIS AWS Foundations Benchmark v1.2.0](../facts/security-hub.md#security-hub-cspm-default-standards)
  say: CIS AWS Foundations Benchmark version one point two
