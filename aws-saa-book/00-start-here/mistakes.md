# Mistakes log

## Cause codes (1 min)
<!-- section: role=method; route=fast; minutes=1 -->

Give each miss one code.

- **K** did not know: read the subsection the explanation links.
- **C** confused two similar things: read the 45 Decision atlas page for that pair.
- **W** missed a word in the stem: cover the options, name the constraint, then read.
- **T** time: answer, flag, move on, return at the end.
- **D** dated question that assumes an old limit: read the chapter's Changed recently entry. On the exam, choose [the best available answer](../facts/exam.md#exam-choose-best-available-answer).

Older practice material can assume old limits. When a service changes, AWS will [replace exam questions determined to be impacted by the change](../facts/exam.md#exam-changed-service-questions-replaced). If a question on the exam still looks dated, choose the best available answer.
